已检查 ACTIVE 合同 v4、字段规范补充、S1.2 计划 / 交接，以及 config.py、main.py、

  当前 Id/Path。字段覆盖应进入 services 职责，最终覆盖后的 Id/Path 才能驱动映射。

- bypass 经 PlaybackHandler.remember_media_sources() 记录上游真实映射并原文返回，不应用字段表。

允许修改 config.py、main.py、services/、必要的 handler 适配、JellyfinProxy.toml、README、
