   插件清单。重跑 / B 复现按锁定摘要运行。就绪后读取服务器实际版本；不符立即失败，不以
   `latest`、相似版本号、网页或标签代替运行核实。不可取得时记录 BLOCKED 交 B / A 处理。
3. 用该版本支持的初始化 / 用户 / 媒体库 API 建专属库，至少两个测试用户 / token、两个设备身份、

   凭据仅进专属私有文件 / 进程环境，不进命令行、Git 或证据包；目录 0700、文件 0600。
4. 素材包括可播放本地短片、指向受控 HTTP(S) 服务的 STRM、第二个独立媒体源及元数据 / 图片，
   避免公共抓取依赖。可用固定镜像内工具补足宿主 ffmpeg 缺口，记录工具摘要、参数与素材 SHA256。

   同时访问；不依赖仅一侧可解析的容器名称，不偷偷替换最终 Location。
5. 优先探测同一真实 MediaSource.Id 的有效 HTTP(S)→本地或无效 Path→有效 HTTP(S)转换。
   只改专属素材并用受支持刷新形成真实返回，记录每步 Item / source ID、原响应与刷新过程。

   不拷入当前未提交业务文件。以明确的隔离 TOML 和清理过相关覆盖变量的子进程环境启动。
   B-on / B-off 除缓存开关、端口 / 日志位置外输入一致：原 TTL 21600、容量 4096，B-off 仅关闭
   JSON 缓存。相同测试客户端策略覆盖普通、仅 Playback、仅 Video、全局、重叠、旧缓存绕过。
7. J 直连先核实能力。B 上游可串接透明观测入口，每次请求必须真送到同一 12.3；不缓存、合成、
   重试、跟随重定向、吞错或改认证 / 正文 / 路径。登记允许的 HTTP hop-by-hop / representation
   适配；唯一请求 ID 关联输入、真实事务及输出，健康检查 / 初始化 / 刷新与场景计数分开。
   J 直连及经观测入口的探针须证明观测未改变结论。
8. 绕过字节与字段比较针对**同次上游事务**，不另发可能产生新会话的 J 请求。有限 JSON 只存
